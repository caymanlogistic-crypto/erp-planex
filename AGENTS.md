# AGENTS.md — входной файл для ИИ-агентов

## Ты работаешь в проекте ERP PLANEX

ERP PLANEX — ERP-система для управления логистическими перевозками.
Разработка ведётся ИИ-агентами. Основной кодер: KILO + DeepSeek.

## Обязательная последовательность перед началом работы

1. Прочитай `docs/ai/PROJECT_STATUS.md` — пойми текущий этап.
2. Прочитай `docs/ai/DECISIONS_LOG.md` — изучи все утверждённые решения.
3. Прочитай `docs/ai/AGENT_WORK_LOG.md` — узнай, что уже сделано.
4. Прочитай профильные документы из `docs/architecture/`, `docs/business/`, `docs/ui/`, относящиеся к твоей задаче.

## Правила работы

- **Не придумывай** бизнес-правила, роли, юридические требования, бухгалтерскую логику.
- **Обновляй логи** после каждой задачи в `docs/ai/AGENT_WORK_LOG.md`.
- **Обновляй статус** проекта в `docs/ai/PROJECT_STATUS.md`.
- **Завершай задачу** только через FINAL REPORT со статусом.
- **Архитектурные решения** записывай в `docs/ai/DECISIONS_LOG.md`.
- **Любые изменения статуса** фиксируй в `docs/ai/PROJECT_STATUS.md`.
- Если данных недостаточно — ставь статус `NEEDS_OWNER_DECISION` и останавливайся.
- Бизнес-код не пиши без отдельного задания.
- Не меняй утверждённую архитектуру без записи решения.
