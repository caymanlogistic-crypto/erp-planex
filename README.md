# ERP PLANEX

ERP-система для управления логистическими перевозками.

## Разработка

Проект разрабатывается ИИ-агентами. Основной исполнитель кода: **KILO + DeepSeek**.

Рабочая папка: `C:\Users\Vladimir\Desktop\PLANEX\SITE\erp\`

## Документация

Вся проектная документация находится в `docs/`:

| Папка | Назначение |
|-------|------------|
| `docs/ai/` | Правила агентов, статус проекта, логи работы, решения |
| `docs/architecture/` | Архитектура, БД, фича-флаги, права, развёртывание |
| `docs/business/` | Глоссарий сущностей, бизнес-процессы |
| `docs/ui/` | Стандарты интерфейса, паттерны форм и таблиц |

## Перед началом любой задачи

Каждый агент обязан прочитать (в порядке очерёдности):

1. `docs/ai/PROJECT_STATUS.md` — текущий этап и фокус проекта
2. `docs/ai/DECISIONS_LOG.md` — все утверждённые решения
3. `docs/ai/AGENT_WORK_LOG.md` — журнал выполненных работ
4. Профильные документы из `docs/architecture/`, `docs/business/`, `docs/ui/` по задаче

## Обязанности агентов

- Вести логи работы в `docs/ai/AGENT_WORK_LOG.md`
- Актуализировать `docs/ai/PROJECT_STATUS.md` после каждой задачи
- Фиксировать архитектурные решения в `docs/ai/DECISIONS_LOG.md`
- Завершать задачу только через FINAL REPORT
- Не придумывать бизнес-правила без подтверждения владельца
- Не писать бизнес-код без отдельного задания
- При нехватке данных ставить статус `NEEDS_OWNER_DECISION`
