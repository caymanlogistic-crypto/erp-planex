Shell / Navigation

ERP PLANEX approved pattern
AI USAGE NOTE: Use this shell, topbar and left navigation for ERP PLANEX layouts. Sidebar structure: .nav-group sections (Главная / Операции / Справочники / Документы / Аналитика), each .nav-item can carry .is-active (current sub-item is the target), .is-parent + .is-open (module open with active child), a .nav-count / .nav-count.is-alert badge, and an expandable .nav-sub with .nav-sub-item rows (.is-active for current, .sub-count / .sub-count.is-alert for numbers). Do not create a second sidebar/topbar, floating menu, SaaS header or separate page shell. Base classes: .app, .topbar, .sidebar, .nav-item, .nav-sub, .nav-sub-item.

Statuses / Badges

ERP PLANEX approved pattern
AI USAGE NOTE: Use these badges for operational statuses, flight statuses and document states. Badge fill comes from the chart series palette (--badge-ok/warning/danger/neutral/archived-bg), border and text use the matching dark-edge tone (--badge-*-edge) for a sharp contour — no dot markers, no tone-on-tone borders. .badge and .doc-status are separate vocabularies — do not mix .badge variants into a .doc-status row or vice versa; .doc-status now covers ok/warning/pending/rejected/archived. Do not introduce candy colors or Bootstrap badges. Base classes: .badge, .flight-status, .doc-status.

Responsive rules

ERP PLANEX approved pattern
AI USAGE NOTE: This reference is desktop-first. Tables scroll horizontally on smaller widths; they must not silently become cards without a separate approved mobile design.
1920 desktopОсновной режим: полноценный sidebar, topbar, плотные таблицы, inspector/panels.
1440 desktopМинимальная production-ширина: сохранять таблицы и shell без разрыва сетки.
1024 fallbackCompact/tablet fallback: таблицы уходят в horizontal scroll, панель не превращается в карточки без решения.
390 critical onlyMobile fallback только для критических действий, если production будет это поддерживать. Sidebar не должен ломать контент.
