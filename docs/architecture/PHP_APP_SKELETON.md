# ERP PLANEX — PHP_APP_SKELETON

## Назначение

Минимальный технический PHP-каркас проекта. Создан для того, чтобы на его основе безопасно наращивать:
- SUPERADMIN;
- локальную ERP;
- маршруты;
- конфигурацию;
- подключение к БД;
- модули.

Каркас не содержит бизнес-функционала. Это чисто техническая оболочка.

## Файлы каркаса

| Файл | Назначение |
|------|------------|
| `public/index.php` | Точка входа. Подключает bootstrap и выводит технический ответ. Без БД, маршрутов, авторизации. |
| `bootstrap/app.php` | Загрузка .env, helper-функций, формирование конфигурации. |
| `config/app.php` | Базовые настройки приложения (имя, окружение, debug, пути). |
| `config/database.php` | Настройки подключения к БД. Читает из env-переменных, не содержит паролей в коде. |
| `app/Support/helpers.php` | Helper-функции `env()`, `base_path()`, `storage_path()`. |
| `app/Core/` | Зарезервировано под ядро (контейнер, роутер — на будущих этапах). |
| `app/Http/` | Зарезервировано под HTTP-слой (контроллеры, middleware — на будущих этапах). |

## Переменные окружения

### `.env.example`
- Хранится в git.
- Содержит примеры переменных без реальных паролей.
- Используется как шаблон для создания локального `.env`.

### `.env`
- Локальный файл, **не коммитится** (добавлен в `.gitignore`).
- Содержит реальные настройки подключения к БД для машины разработки.
- Пароль БД существует только в локальном `.env` и не попадает в git.
