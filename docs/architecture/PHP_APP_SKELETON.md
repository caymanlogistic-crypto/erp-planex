# ERP PLANEX — PHP_APP_SKELETON

## Назначение

Минимальный технический PHP-каркас проекта. Создан для того, чтобы на его основе безопасно наращивать:
- SUPERADMIN;
- локальную ERP;
- маршруты;
- конфигурацию;
- подключение к БД;
- модули.

Каркас не содержит бизнес-функционала. Это чисто техническая оболочка.

## Файлы каркаса

| Файл | Назначение |
|------|------------|
| `public/index.php` | Точка входа. Подключает bootstrap и выводит технический ответ. Без БД, маршрутов, авторизации. |
| `bootstrap/app.php` | Загрузка .env, helper-функций, формирование конфигурации. |
| `config/app.php` | Базовые настройки приложения (имя, окружение, debug, пути). |
| `config/database.php` | Настройки подключения к БД. Читает из env-переменных, не содержит паролей в коде. |
| `app/Support/helpers.php` | Helper-функции `env()`, `base_path()`, `storage_path()`, `e()`. |
| `app/View/layouts/main.php` | Базовый технический layout ERP-интерфейса. |
| `app/View/components/` | Простые PHP-компоненты UI-фундамента. |
| `app/View/pages/ui_demo.php` | Техническая demo-страница UI-фундамента без бизнес-логики. |
| `public/assets/css/app.css` | Базовые дизайн-токены и стили layout/components. |
| `public/assets/js/app.js` | Минимальный JS-файл UI-фундамента. |
| `app/Core/` | Ядро: `Database.php` — PDO-обёртка для подключения к БД. |
| `app/Http/` | HTTP-слой: `Router.php` — простой GET-роутер. |

## Переменные окружения

### `.env.example`
- Хранится в git.
- Содержит примеры переменных без реальных паролей.
- Используется как шаблон для создания локального `.env`.

### `.env`
- Локальный файл, **не коммитится** (добавлен в `.gitignore`).
- Содержит реальные настройки подключения к БД для машины разработки.
- Пароль БД существует только в локальном `.env` и не попадает в git.

## Текущее состояние

- `public/index.php` — точка входа. Подключает bootstrap, Database, Router, UI-компоненты, layout и demo-страницу.

- PDO-обёртка `Database` создана: lazy-подключение, настройки PDO, безопасная обработка ошибок.

- SUPERADMIN пока **не реализуется**.
- Локальная ERP пока **не реализуется**.
- Авторизация отсутствует.
