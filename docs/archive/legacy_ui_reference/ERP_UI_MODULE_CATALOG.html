ERP PLANEX UI Module Catalog

Формализованный HTML-каталог UI-модулей, извлечённых из STYLE ERP. Дизайнер проектирует page handoff только из этих модулей и профильных MD.

MODULE AVAILABILITY RULE

mandatory gate
Allowed sourcesДизайнер имеет право проектировать страницу только из формализованных модулей, описанных в этом каталоге и MD: STYLE_ERP_EXTRACTED_RULES.md, DESIGN_CODE_INTEGRATION.md, PAGE_PATTERN.md, FORMS_STANDARD.md, TABLES_STANDARD.md, pages/_PAGE_TEMPLATE.md.
Missing moduleЕсли подходящего модуля нет, дизайнер обязан остановиться и вернуть BLOCKED: NEEDS_UI_MODULE_EXPANSION. Нужно описать отсутствующий модуль, назначение, место применения, элементы, состояния, возможность вывести из STYLE ERP и какие MD/HTML files расширить.
ForbiddenНельзя придумывать новый модуль прямо в page handoff, заставлять кодера изобретать UI, писать "посмотри STYLE ERP", ссылаться на STYLE ERP вместо точного MD/handoff/catalog.

DESIGNER MODULE SELECTION RULES

required in page handoff
Decision proofДизайнер обязан указать, почему выбран модуль, почему не выбран другой, где он расположен, какая роль блока на странице, какое действие главное, какие действия второстепенные, какие элементы временно disabled и какие состояния нужны.
Page handoffВ page handoff обязательны: main page purpose, primary work object, main layout, primary/secondary actions, table/form/inspector/filters/modal required YES/NO with reasons, states, modules used with reasons, modules explicitly not used with reasons.
Blocked ruleЕсли дизайнер не может выбрать подходящий модуль из каталога, статус только BLOCKED: NEEDS_UI_MODULE_EXPANSION. Кодеру нельзя передавать неизвестный UI-модуль.
