# ERP PLANEX — CONTRACTOR_CREW_WORKFLOW

## Подрядчик

Подрядчик — единая сущность для перевозчика/экспедитора/подрядчика.

## Данные подрядчика

Подрядчик может иметь:
- карточку компании;
- документы;
- водителей;
- машины;
- экипажи.

## Водители и машины

Водители и машины могут быть созданы отдельно.

Пример:
```text
ООО РОМАШКА
  Водители:
    Иванов
  Машины:
    А999АА99
    И999ПП99
```

## Экипажи

Экипаж создаётся как жёсткая комбинация:

```text
Подрядчик + Машина + Водитель
```

Пример:
```text
ООО РОМАШКА
  Экипаж 1: Иванов + А999АА99
  Экипаж 2: Иванов + И999ПП99
```

## Правило истории

Рейс должен ссылаться на `crew_id`.

Для защиты истории рейса желательно хранить snapshot:
- название подрядчика;
- ФИО водителя;
- номер машины.

Так старые рейсы не исказятся, если карточки изменятся.
