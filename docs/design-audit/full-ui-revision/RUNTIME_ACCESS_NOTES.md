## Проверенные гранты доступа

- **logist_runtime_1**: владелец подрядчика 1, водителя 1, ТС 1 и т.д. — видит все свои записи.
- **logist_runtime_2**: имеет грант-доступ к экипажу 1, возможно к другим — видит ограниченный набор записей.
- Типы грантов: view (просмотр), edit (редактирование).
- Каскад грантов: грант на экипаж → связанные DVB, водитель, сцепка, единицы ТС.

---

## Сводка ролевых доступов

- **SUPERADMIN**: все компании, мониторинг только для чтения, может управлять компаниями/пользователями, но без редактирования бизнес-данных.
- **COMPANY_OWNER**: все записи компании 9, может управлять пользователями, выдавать гранты, видеть удалённые документы.
- **LOGIST (владелец)**: записи, созданные им самим, полное редактирование/архивирование своих записей, нет UI грантов.
- **LOGIST (грант):** записи через гранты, просмотр или редактирование согласно уровню гранта, нет UI грантов.

- `/company/logists` — только COMPANY_OWNER (403 для логиста)

- `/company/logists/{id}/edit` — только COMPANY_OWNER
- Блоки UI грантов — только COMPANY_OWNER видит их на карточках сущностей
- Действия архивирования — логист может архивировать только собственные записи

## Известные состояния

- **Пустые списки**: logist2 видит пустые списки подрядчиков/водителей/ТС (нет собственных записей, нет грантов).
- **Доступ запрещён**: при попытке logist2 просмотреть собственные записи logist1 может отображаться сообщение «У вас нет доступа».
- **Просмотр по гранту**: logist2 при просмотре экипажа 1 (через грант) видит режим только для чтения.
- **Редактирование по гранту**: если logist2 имеет грант edit на экипаж 1, видит кнопку редактирования.
