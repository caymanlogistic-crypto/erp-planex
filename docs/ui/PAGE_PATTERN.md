# ERP PLANEX — PAGE_PATTERN

## Стандарт страницы модуля

Каждая страница должна иметь:

```text
Заголовок
Краткое описание
Основное действие
Фильтры/поиск при необходимости
Таблицу или карточки
Статусы
Действия
Пустое состояние
Ошибки
```

## Пустое состояние

Если данных нет, пользователь должен понимать, что делать.

Пример:
```text
Клиенты пока не добавлены.
Добавьте первого клиента, чтобы создать заявку и рейс.
```

## Ошибки

Ошибки должны быть понятными обычному пользователю.
