# ERP PLANEX — UI_UX_RULES

## Общий принцип

ERP PLANEX — рабочая система для реальных сотрудников. Интерфейс должен быть понятным, строгим и удобным.

Дизайн-код интегрируется по правилам `docs/ui/DESIGN_CODE_INTEGRATION.md`.

Перед активной разработкой бизнес-страниц должен быть создан единый UI-фундамент: layout, токены, базовые компоненты, стили форм, таблиц, статусов, ошибок и пустых состояний.

## Запрещено

- Делать хаотичные формы.
- Использовать разные стили кнопок без системы.
- Создавать разрозненные стили для каждой страницы.
- Делать лендинг вместо рабочей ERP.
- Показывать технические ошибки пользователю.
- Прятать важные статусы.
- Делать непонятные действия без подтверждения.

## Обязательные UX-принципы

- На странице должно быть понятно, что делать дальше.
- Таблицы должны быть читаемыми.
- Формы должны иметь понятные label.
- Обязательные поля должны быть явно отмечены.
- Ошибки должны быть написаны человеческим языком.
- У опасных действий должно быть подтверждение.
- Статусы должны быть видимыми.
